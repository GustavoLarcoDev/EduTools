Cómo funciona

De la carrera al recurso en tres pasos

  1. 1

    Elige tu carrera

    Filtra el catálogo por tu carrera y ve solo el material que te sirve.

  2. 2

    Aprende con tutoriales

    Guías paso a paso, con tiempo de lectura y la herramienta que necesitas.

  3. 3

    Descarga herramientas

    Plantillas, guías y hojas de cálculo listas para usar en tus entregas.

Funcionalidades

Pensada para estudiar mejor y administrar sin fricción

Una aplicación full stack con frontend en Next.js y una API REST en Django, con autenticación por roles y contenido Premium.

Ver las carreras

Tutoriales por carrera

Contenido agrupado por carrera, con búsqueda y filtros instantáneos y lectura en un panel lateral.

Herramientas descargables

Cada recurso tiene su archivo, su carrera y, si aplica, los tutoriales que lo explican.

Contenido Premium

Los recursos Premium se filtran en el servidor y el flujo de suscripción está preparado para Stripe Checkout.

Roles admin y estudiante

Autenticación JWT con roles: los administradores gestionan el catálogo y los estudiantes lo consumen.

Bajo el capó

Un frontend en Next.js sobre una API REST en Django

El cliente consume la API con Axios y tokens JWT. En esta versión publicada, una capa de datos de ejemplo reemplaza al backend para que puedas recorrer la aplicación completa sin servidor.
